Tips: the Review window, and capturing long web pages

Every screenshot opens in the Review window first: annotate, blur sensitive details, crop or add text, then Copy (to paste into Teams, Outlook, Word...), Save or Cancel.

Long web page? Browsers don't let a web page scroll other windows, so full-page capture isn't possible here. Use the browser's own tool instead: Edge – press Ctrl+Shift+S → Capture full page; Chrome – press F12, then Ctrl+Shift+P → Capture full size screenshot. Then use Annotate an image... on the result.
